Return & Exchange Policy

退换货政策

生效日期：2026年08月01日

思迈威 SMART WELLNESS 致力于为用户提供高品质的运动装备和健康产品。

为了保障用户权益，同时确保产品质量与服务标准，我们制定以下退换货政策。

一、适用范围

本政策适用于通过 思迈威 SMART WELLNESS 官方网站、官方商城及授权渠道购买的商品。

不同商品可能因产品性质不同，适用不同的退换货规则，具体以商品页面说明为准。

二、退货申请条件

用户在收到商品后，如符合以下条件，可以申请退货：

  • 商品在规定退货期限内
  • 商品未经使用，不影响二次销售
  • 商品包装、配件、说明书及赠品完整
  • 商品不存在人为损坏

建议用户收到商品后及时检查产品状态。

三、退货期限

除特殊商品外：用户可在收到商品后的 48 小时内提交退货申请。

超过退货期限，如商品存在质量问题，我们将根据实际情况提供售后处理方案。

四、不支持退货的情况

以下情况可能无法办理退货：

  • 商品已使用并影响再次销售
  • 商品存在人为损坏
  • 缺少包装、配件或赠品
  • 超过退货申请期限
  • 根据商品性质不适合退货的产品

例如：已拆封使用的个人健康用品、定制类商品，或因卫生原因不适合再次销售的商品。

五、换货政策

如商品存在以下情况，用户可以申请换货：

  • 收到商品与订单不符
  • 商品存在质量问题
  • 运输过程中造成损坏

换货申请需提供：订单信息、商品照片或相关证明、问题说明。审核通过后，我们将安排换货流程。

六、退款方式

退货审核通过并收到商品后，我们将在合理时间内处理退款。退款金额：

  • 商品费用按照实际支付金额退还
  • 运费根据具体情况处理

退款时间可能因支付方式和银行处理流程有所不同。

七、质量问题处理

如果商品存在质量问题，请在收到商品后及时联系我们。思迈威 SMART WELLNESS 将根据具体情况提供：

  • 免费维修
  • 更换产品
  • 退款处理
  • 其他合理解决方案

我们会尽力确保每一位用户获得满意的购物体验。

八、退换货流程

申请退换货：

  • 联系 思迈威 SMART WELLNESS 客服
  • 提供订单信息及问题说明
  • 等待审核确认
  • 按指引寄回商品
  • 完成退款或换货

未经确认直接寄回商品，可能导致处理延迟。

九、运费说明

因用户个人原因产生的退货：退回运费通常由用户承担。

因以下原因产生的退换货，相关费用由 思迈威 SMART WELLNESS 承担：

  • 商品质量问题
  • 发错商品
  • 运输损坏

十、政策更新

思迈威 SMART WELLNESS 有权根据业务发展、法律法规及服务需求调整本政策。

更新后的政策将在官方网站公布，并注明生效日期。

十一、联系我们

如您需要申请退换货或咨询售后服务，请联系我们：

品牌名称：思迈威 SMART WELLNESS

官方网站：www.smartwellness.com.cn
